# UPES 100 Days of Code

A collection of C solutions for the UPES 100 Days of Code challenge.

## Repository structure

Solutions are grouped by challenge day. Each source file includes the problem statement, sample cases, implementation, and complexity notes where applicable.

## Compile and run

Use a C compiler such as GCC:

```sh
gcc Day-64/Q114.c -std=c11 -Wall -Wextra -pedantic -o solution
./solution
```

Replace the source path with the solution you want to run.

## Current progress

The latest committed solutions are Day 63, Q113 (the kth smallest array element) and Day 64, Q114 (the longest substring without repeating characters).

New solutions should preserve the existing day/question naming convention and include input validation and useful comments.
